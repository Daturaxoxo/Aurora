# Utility Mod Pack by UnLuckyLust v1.2.0
A growing collection of useful tools, trackers, and gameplay improvements.
Since pak mods can conflict, I am merging all my existing and upcoming mods into one utility package.

## Features
- In-game Menu to control mod functions
- Options state will be saved across sessions
- Work with all game versions (Global, CN, TW, Steam, Epic Games)
- The mod uses PlayerState instead of GameState, allowing compatibility with other mods that also modify GameState

## Included Mods
More mods will be added over time as development continues.

- Outline Control: 
Control the thickness of all characters and NPCs outline.
[Outline Control Preview](https://www.youtube.com/watch?v=g91P1cauXDQ)

- Collectibles Tracker:
Show direction to the closest collectible item.
Includes overworld collectibles, NPC-carried items, illegal activities, and all Pink Paw heist collectibles.
[Collectibles Tracker Preview](https://www.youtube.com/watch?v=3JMrw6xMghE)

- Awakening 6 Effects:
A toggle to disable A6 Effects for all characters.


## Known Issues
- Pink Paw Tracker: In some locations, item directions may be reversed: items shown ahead may be behind you, and vice versa.
- Overworld Tracker: Some objects, such as safes, Illegal City Activities, and potentially others, remain tracked after looting/interacting because they contain respawnable objects and aren’t fully removed by the game.


## Toggle Keys
The mod includes runtime toggle so you can control the settings while in-game.
The toggle keys can be customized through the in-game menu.
- 5 = Toggle In-Game Menu
- CTRL + X = Lock / Unlock control keys
